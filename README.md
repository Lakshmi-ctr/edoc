# 🩺 Doctor Appointment Booking System

A web-based Doctor Appointment Booking System developed using **PHP, MySQL, HTML, CSS, and JavaScript**. The system allows patients to book appointments online, doctors to manage schedules, and administrators to manage the entire platform.

## 🌐 Live Demo
**Website:** https://lakshmiedoc.infinityfreeapp.com

## 💻 Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Apache (XAMPP)

## ✨ Features

### 👨‍💼 Admin
- Add, edit, and delete doctors
- Schedule doctor sessions
- View patient details
- Manage patient bookings

### 👨‍⚕️ Doctor
- View appointments
- View scheduled sessions
- View patient details
- Edit account settings
- Delete account

### 👤 Patient
- Register and log in
- Book appointments online
- View appointment history
- Edit account settings
- Delete account

## 🚀 Installation
1. Start Apache and MySQL in XAMPP.
2. Copy the project into the `htdocs` folder.
3. Create a database named `edoc`.
4. Import the provided SQL file.
5. Update the database credentials in `connection.php`.
6. Open the project in your browser.
